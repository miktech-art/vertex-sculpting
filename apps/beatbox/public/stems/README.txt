BEATBOX AUDIO SAMPLES

The five user-supplied WAVs are included here with these exact lowercase names:
kick.wav, clap.wav, cymbal.wav, synth.wav, bass.wav

Replace these source copies, then run npm run build:beatbox (or npm run build)
from the repository root. The build copies them to dist/beatbox/stems/.
Do not edit the generated copies; a rebuild replaces them.
