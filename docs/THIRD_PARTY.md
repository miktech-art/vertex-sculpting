# Third-party files and provenance

- **MediaPipe Tasks Vision 1.1.1 and Hand Landmarker model**: bundled in `apps/sculpt/vendor/mediapipe/`. The upstream Apache 2.0 license and source/model URLs remain beside the files in `LICENSE` and `NOTICE.md`.
- **Three.js 0.170.0**: Beatbox runtime dependency, installed from npm using `apps/beatbox/package-lock.json`; MIT license distributed with that package.
- **Beatbox / Vertex Sequencer**: supplied by the collaborator as `vertex-sequencer-src.zip`. Original architecture, decisions, roadmap, README, and agent notes are retained under `apps/beatbox/docs/` as historical context.
- **Five WAV stems**: user-supplied files retained in `apps/beatbox/public/stems/`. The upstream Beatbox documentation attributes them to HNTR's “Shook Ones Pt. III”. No new license is assigned to these samples by this repository.

No repository-wide open-source license has been selected. Third-party components retain their respective terms.
